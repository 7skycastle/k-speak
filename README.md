# Korean First Talk

`korean-first-talk` is a mobile-first Korean learning app for new international learners. It supports guest onboarding, Day 1 lesson progress, voice comparison without pronunciation scoring, rule-based review scheduling, local persistence, and a Supabase-ready sync boundary.

## Commands

```bash
npm install
npm run dev
npm run build
npm run typecheck
npm run lint
npm run test
```

## Environment

Copy `.env.example` to `.env.local` when a new Supabase project is ready. Do not use the previous `K_study` project or project ID `bcpoowcqvqynpciiqoav`.
